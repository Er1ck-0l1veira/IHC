# Protótipo Discord — Avaliação Cooperativa

Protótipo estático de alta fidelidade para fins acadêmicos. Não é um produto oficial do Discord e não se conecta aos servidores reais.

## Como executar localmente
1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador moderno.

## Como publicar gratuitamente no GitHub Pages
1. Entre no GitHub e crie um repositório público, por exemplo `prototipo-discord`.
2. Envie os três arquivos: `index.html`, `style.css` e `script.js` (também pode enviar este README).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na mesma página, normalmente:
   `https://SEU-USUARIO.github.io/prototipo-discord/`

## Funcionalidades simuladas
- Navegação entre servidores e canais.
- Envio de mensagens e interação de resposta.
- Conversas privadas com contatos fictícios.
- Entrada e saída simuladas de canal de voz.
- Preferências de notificações.
- Layout responsivo para telas menores.

## Observação acadêmica
O protótipo usa conteúdo fictício e interações locais no navegador. A chamada de voz, notificações do sistema e comunicação entre usuários são apenas simulações visuais.
